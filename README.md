## About

I'm a data scientist with a B.S. in Network Engineering and Security and an M.S. in Data Science. My recent work is in the telecom and utility industries, building operational, financial, and risk-based data pipelines and analyses. I pair complex analytics with modeling, ML, and mathematical optimization, from IEEE Std 738 thermal ratings across 9 billion+ records to AI tools that read engineering diagrams.

## Featured work

- **Network-wide conductor thermal ratings:** an ETL pipeline implementing IEEE Std 738-2023 for tens of thousands of overhead conductors, solved with LP / MIP / NLP optimizers.
- **Object detection for engineering diagrams:** a computer-vision prototype (YOLO, PyTorch, Hugging Face) with swappable OCR backends and a human-in-the-loop review step, tracked in MLflow.
- **[Power Project](https://github.com/ethan-gueck/power_project):** predicting lagging power factor. A tuned random forest reached an RMSE of 0.55 percentage points on unseen data.
- **[Ethan's NN](https://ethan-gueck.github.io/#nn):** every flashcard I study as a neuron, filled in as I build each formula into an interactive page. Pages live in one repo per domain, starting with [algebra](https://github.com/ethan-gueck/algebra), on a shared library in [portfolio-projects](https://github.com/ethan-gueck/portfolio-projects).
